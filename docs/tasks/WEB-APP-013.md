# WEB-APP-013 公司链接与搜索建议交互修复

- 状态：PLANNED
- 用户价值：投递列表的公司名直接作为招聘网站链接，关键字建议完整显示并能在点击页面其他区域后关闭。
- 范围：修复 `ApplicationsView` 公司列的链接呈现、搜索建议浮层定位和外部点击关闭行为。
- 非范围：不改变公司/岗位 API、搜索条件、分页、公司招聘 URL 数据、手机端适配或插件行为。
- 依赖：WEB-APP-008 公司关键字建议、APP-012 全局公司招聘网站投影。
- 允许修改范围：项目管理仅 `docs/tasks/`、`docs/acceptance/`；测试仅 `frontend/tests/`、`tests/e2e/`、`docs/test-reports/`；实现仅 `frontend/src/`、`docs/implementation-notes/`。

## 业务规则与公开契约

1. 公司有合法 HTTP(S) 招聘网站时，公司名称本身是唯一可见链接文本，点击新窗口打开招聘网站；页面不再把完整 URL 作为单独可见文本展示。
2. 公司没有合法招聘网站时，公司名仍以普通文本显示，不生成伪链接。
3. 关键字建议浮层必须突破查询卡片和父容器的裁剪，完整显示在输入框下方，拥有足够层级覆盖后续内容。
4. 建议浮层打开后，点击搜索控件外任意页面区域必须关闭；点击输入框、建议项、重试按钮等浮层内部控件不能被外部关闭逻辑误处理。Escape、提交、重置的既有关闭行为继续有效。
5. 关键字建议的加载、筛选、选择、请求参数和认证错误行为保持不变。

## 验收标准

- [ ] 公司名为招聘网站链接文本，完整 URL 不单独显示；无 URL 时为普通文本。
- [ ] 关键字建议不被查询容器裁剪，浮层可完整展示并覆盖相邻内容。
- [ ] 建议打开后点击外部区域关闭，内部点击和选择行为不回归。
- [ ] 关键字选择仍更新搜索并仅提交一次查询，原有登录/加载/失败回归通过。
- [ ] 测试 Agent 先提交稳定 RED；实现 Agent 提交 READY_FOR_TEST；测试 Agent 独立 TEST_PASSED；PM 最后验收 DONE。

## 风险与测试边界

- 测试通过公开 UI、DOM 可见文本/链接属性、浮层可见状态和交互事件验证，不读取生产实现源码。
- 需要覆盖有 URL、无 URL、建议浮层跨容器显示、点击外部关闭、点击内部建议项和 Escape。
