# APP-007 删除投递记录

- 状态：`DONE`
- 用户价值：用户可删除不再需要的记录，且不能删除其他用户数据。
- 范围：`DELETE /api/v1/applications/{id}/`、硬删除、权限与幂等错误。
- 非范围：回收站、软删除、批量删除、前端确认对话框。
- 依赖：`APP-003`。
- 允许修改范围：测试 Agent：`backend/tests/`、`docs/test-reports/`；实现 Agent：`backend/apps/`、`backend/config/`、`docs/implementation-notes/`；项目管理 Agent：仅 `docs/requirements/`、`docs/tasks/`、`docs/acceptance/`。

## 业务规则与公开契约

- `DELETE /api/v1/applications/{id}/` 需认证；本人记录删除成功返回 `204 No Content`，数据库记录不存在。
- 其他用户记录和不存在 ID 均返回 `404 NOT_FOUND`，不能通过错误差异泄露存在性。
- 未认证返回 `401`；删除必须是硬删除，不引入 `deleted_at`。

## 验收标准

- [x] 本人记录删除后列表和详情均不可见，数据库行已移除。
- [x] 跨用户删除为 404 且目标记录保持不变。
- [x] 不存在 ID 和重复删除行为稳定。
- [x] 未认证删除为 401。
- [x] 测试先确认删除行为缺失，再由实现和独立测试完成。

## 风险与测试边界

- 用户级联删除由 `APP-001` 模型测试覆盖；本任务验证记录级删除。
- 前端删除前确认和当前页回退由 `WEB-APP-004` 负责。
