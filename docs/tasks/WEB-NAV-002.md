# WEB-NAV-002 侧栏收起控制与新增投递布局

- 状态：`DONE`
- 用户价值：用户能收起/展开桌面侧栏，并在新增投递页保持应用内导航。
- 范围：桌面侧栏可见性控制，以及 `/applications/new` 与共享侧栏的布局集成。
- 非范围：侧栏视觉重设计、窄屏交互重新设计、投递表单字段或提交逻辑变更。
- 依赖：`WEB-NAV-001`、`WEB-APP-003`、`WEB-APP-005` 已完成。
- 允许修改范围：项目管理 Agent 仅 `docs/tasks/`、`docs/acceptance/`；测试 Agent 仅 `frontend/tests/`、`docs/test-reports/`；实现 Agent 仅 `frontend/src/`、`docs/implementation-notes/`。

## 业务规则与公开契约

- 桌面侧栏展开时提供可访问的“收起侧边栏”控制；激活后侧栏导航隐藏，页面主内容仍可操作。
- 侧栏收起后提供“展开侧边栏”控制；激活后恢复导航项和原布局。
- 登录用户打开或从投递列表进入 `/applications/new` 时，共享侧栏与“我的投递进度”“日历”等既有导航项仍可见。
- 新增投递页可通过侧栏返回投递列表；投递表单正常显示和操作。
- 日历页和投递列表已有的导航行为保持不变。
- 窄屏侧栏继续使用菜单按钮打开临时抽屉；本任务只修桌面收起控制与新增页布局。

## 输入、输出与错误行为

- 输入：已认证用户在桌面收起/展开侧栏，打开 `/applications/new` 并使用侧栏导航。
- 输出：可访问的收起/展开状态切换；新增页呈现共享导航；返回入口将路由切至 `/applications`。
- 未登录路由仍按现有认证守卫处理；不修改表单校验、API 错误或数据提交行为。

## 验收标准

- [ ] 桌面投递列表显示侧栏收起控制，收起与恢复导航均可用。
- [ ] `/applications/new` 直接打开和从列表进入时显示共享侧栏与新增表单。
- [ ] 新增页侧栏的投递入口可返回 `/applications`。
- [ ] 日历与投递列表回归通过；窄屏菜单行为不退化。
