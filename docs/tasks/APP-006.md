# APP-006 修改与阶段时间清空

- 状态：`DONE`
- 用户价值：用户可编辑记录并填写、修改或清空任一面试阶段时间。
- 范围：`PATCH /api/v1/applications/{id}/`、部分更新、六个阶段时间的 ISO/null 语义。
- 非范围：删除、批量编辑、乐观锁、前端编辑/快速单元格组件。
- 依赖：`APP-003`、`APP-001`。
- 允许修改范围：测试 Agent：`backend/tests/`、`docs/test-reports/`；实现 Agent：`backend/apps/`、`backend/config/`、`docs/implementation-notes/`；项目管理 Agent：仅 `docs/requirements/`、`docs/tasks/`、`docs/acceptance/`。

## 业务规则与公开契约

- `PATCH` 只修改请求中提交的字段；未提交字段保持不变。
- 时间字段接受带时区 ISO 8601 或 JSON `null`；`null` 表示清空，空字符串不表示清空并应被拒绝。
- `id`、`user`、`current_stage`、创建时间不可覆盖；归属由 QuerySet 保护。
- 并发策略为第一期最后一次写入生效；成功返回 `200` 和更新后的完整记录。

## 验收标准

- [x] 本人只 PATCH 一个字段时其他字段不变。
- [x] 六个阶段时间可分别设置、修改和用 `null` 清空，当前阶段随之派生。
- [x] 跨用户 PATCH 返回 404，数据库不发生变化。
- [x] 只读字段伪造不能改变归属或审计时间语义。
- [x] 非法时间/状态返回字段错误；测试先 RED 后独立复测。

## 风险与测试边界

- 数据库时间以 UTC 保存、API 返回带时区格式；转换边界要由测试明确。
- 前端保留失败表单内容和字段错误由 `WEB-APP-003` 负责。
