# WEB-APP-002 投递列表、搜索筛选与分页页面

- 状态：`DONE`
- 用户价值：用户可以浏览、搜索、筛选、排序和分页查看自己的投递进度。
- 范围：`ApplicationsView.vue`、查询区、表格/卡片、分页控件、URL 同步和加载/空结果状态。
- 非范围：新增/编辑表单、删除确认、后端过滤实现。
- 依赖：`WEB-APP-001`、`WEB-AUTH-002`、`APP-003`、`APP-004`、`APP-005`。
- 允许修改范围：测试 Agent：`frontend/tests/`、`tests/e2e/`、`docs/test-reports/`；实现 Agent：`frontend/src/`、`docs/implementation-notes/`；项目管理 Agent：仅 `docs/requirements/`、`docs/tasks/`、`docs/acceptance/`。

## UI 契约

- 顶部显示项目名、当前用户名和退出按钮；提供“新增公司进度”入口。
- 查询区包含关键字、投递状态、当前阶段、投递时间起止、查询和重置；回车/点击查询请求一次。
- 表格展示公司、岗位、状态、六个阶段时间、更新时间和操作；桌面端固定公司/岗位及操作列，窄屏可卡片化。
- 默认第 1 页/20 条；改变筛选、排序或 page size 页码回到 1，仅翻页保留其余条件；状态同步 URL。
- 初次无记录、无结果、网络错误和 401 分别展示可理解状态与操作。

## 验收标准

- [x] 列表请求和展示严格使用当前查询参数及分页响应。
- [x] 搜索、状态/阶段/时间筛选、排序和 page size 交互可观察且重置正确。
- [x] URL 刷新、前进后退可恢复查询状态。
- [x] 加载、空状态、无结果和网络错误不会丢失用户查询。
- [x] 组件测试先 RED，并完成必要 API mock 与独立复测。

## 风险与测试边界

- 并发搜索请求需取消旧请求或只接受最新响应；不能旧响应覆盖新查询。
- 表格操作按钮由 `WEB-APP-003`、`WEB-APP-004` 接入。
