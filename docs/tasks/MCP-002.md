# MCP-002 MCP 写工具第一期

- 状态：`DONE`
- 用户价值：已授权的 AI 客户端可以用标准 MCP 工具把结构化的投递、测评、笔试和面试时间安全写入当前用户自己的进度数据。
- 范围：`applications:write` OAuth scope；`create_application`；`upsert_application_stage`；APP-011 阶段与时间规则；APP-012 公司/岗位隔离与聚合；事务、参数校验、结构化结果和工具白名单。
- 非范围：预览/确认、proposal、幂等、冲突检测、审计，邮箱读取、大模型抽取、删除、保存状态通用修改、stdio、Resources、Prompts、SSE 和任意 REST/SQL 工具。
- 依赖：`MCP-001`（已完成）、`APP-011`（已完成）、`APP-012`（已完成）；详细契约见 `docs/requirements/MCP-002.md`。
- 允许修改范围：项目管理 Agent 仅 `docs/requirements/`、`docs/tasks/`、`docs/acceptance/`；测试 Agent 仅 `backend/tests/`、`docs/test-reports/`；功能实现 Agent 仅 `backend/apps/`、`backend/config/`、`backend/manage.py`、后端运行时依赖、`docs/implementation-notes/`。

## 业务规则与公开契约

- MCP-001 的 `/mcp`、OAuth Resource Server、stateless Streamable HTTP 和当前用户识别继续有效。
- 写工具必须要求 `applications:write`；`applications:read` 仍只允许查询。
- `tools/list` 白名单为 `find_applications`、`create_application`、`upsert_application_stage`；禁止原始 REST、SQL、任意 PATCH 和删除工具。
- `create_application` 使用公司名称/公司 ID、岗位名称、可选带时区投递时间、八值保存状态和非读邮箱来源描述；复用 APP-012 公司，岗位私有数据归当前用户。
- `upsert_application_stage` 只允许 `assessment`、`written_test`、`interview`；写入共享测评/笔试或当前用户岗位面试，支持清空，按 APP-011 规则更新只读 `current_stage`，不得改变 `application_status`。
- 成功结果必须同时提供可读 `content` 和 APP-012/APP-011 公开聚合 `structuredContent`。

## 输入、输出与错误行为

- `create_application`：合法输入必须支持 `company_name` 或 `company_id`、`position_name`、可选 `application_time`、`notes`、八值 `application_status`；成功返回创建/复用标志和完整公开聚合。
- `upsert_application_stage`：合法输入必须支持 `application_id`、必要时 `position_id`、阶段类型、面试轮次/名称、带时区 `scheduled_at` 或 `null`、可选正整数时长；成功返回更新阶段和新的 `current_stage`。
- 缺少/无效 Token：HTTP `401`；缺少 `applications:write`：HTTP `403 insufficient_scope`。
- 参数、状态、阶段、时间、时长或岗位级招聘 URL 非法：工具错误，字段级说明，数据库无变化。
- 不存在、跨用户或不属于目标投递的 ID：`404` 语义，不泄露资源存在性。
- 业务/数据库异常：`isError=true`，不得返回堆栈、SQL、Token、密码或跨用户字段。
