# WEB-APP-003 新增、编辑与阶段时间表单

- 状态：`DONE`
- 用户价值：用户能新增投递记录，完整编辑记录，并通过选择器或文本输入填写/清空各阶段时间。
- 范围：共用 `ApplicationForm.vue`、新增/编辑模式、校验、ISO 转换、字段错误、提交状态和未保存确认。
- 非范围：列表查询、删除确认、后端模型/API 实现。
- 依赖：`WEB-APP-001`、`WEB-APP-002`、`APP-002`、`APP-006`。
- 允许修改范围：测试 Agent：`frontend/tests/`、`tests/e2e/`、`docs/test-reports/`；实现 Agent：`frontend/src/`、`docs/implementation-notes/`；项目管理 Agent：仅 `docs/requirements/`、`docs/tasks/`、`docs/acceptance/`。

## UI 契约

- 新增字段为公司、岗位、状态、投递时间、六阶段时间、备注；时间默认空，提交为 `null`。
- 编辑使用传入数据副本，不直接改表格行；PATCH 只提交变化字段。
- 提交期间禁用重复提交并显示 loading；成功关闭、清空表单并回到第 1 页刷新；失败保留输入并在对应字段显示后端错误。
- 时间选择器支持选择和键盘输入；清空明确发送 JSON `null`。
- 有未保存修改关闭时二次确认。

## 验收标准

- [x] 新增、编辑两种模式字段回填和默认值正确。
- [x] 六阶段时间可设置、修改、清空，ISO/null 传输正确。
- [x] 重复提交被阻止；成功和失败后的表单/列表状态符合契约。
- [x] 后端字段错误能映射到字段，成功前不乐观修改行。
- [x] 组件测试先 RED，核心流程独立复测。

## 风险与测试边界

- 日期显示按浏览器本地时区，API 仍保留带时区 ISO；时区转换由工具测试保护。
- 不在本任务实现后端权限；接口失败由页面统一展示。
