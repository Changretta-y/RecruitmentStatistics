# REL-001 实现说明

- 后端测试环境将 `coverage` 与 `pytest-cov` 纳入 `backend/pyproject.toml` 的锁定 test 依赖，并同步 `backend/uv.lock`。
- 前端 Vitest 使用 `@vitest/coverage-v8`，生成 text/html/json-summary 报告，总体 lines/functions/statements/branches 门槛均为 80%。
- `.github/workflows/ci.yml` 按 Ruff → 后端 pytest/coverage → ESLint/TypeScript → Vitest/coverage → build → Playwright E2E 顺序执行，任一步失败即阻断。
- `scripts/release-rehearsal.ps1` 只接受显式源库、隔离恢复库、备份文件和 PostgreSQL client 目录；缺少 `pg_dump`/`pg_restore`/`psql`/数据库工具会立即失败，不会伪造恢复结果。

本地发布演练示例：

```powershell
uv sync --project backend --frozen --group test
.\scripts\release-rehearsal.ps1 `
  -DatabaseUrl 'postgresql://postgres:postgres@127.0.0.1:5432/postgres' `
  -RestoreDatabaseUrl 'postgresql://postgres:postgres@127.0.0.1:5432/rel001_restore' `
  -BackupFile '.\artifacts\rel001.dump'
```

演练必须使用独立恢复数据库；若本机 PostgreSQL client 或隔离目标不可用，报告必须保持 BLOCKED，不能标记为已完成。
