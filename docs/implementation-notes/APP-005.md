- 已实现行为：
  - 在当前用户 QuerySet 隔离之后执行 search，对 company_name 或 position_name 做不区分大小写的模糊匹配。
  - application_status 仅接受 applied、in_progress、offer、rejected、withdrawn，并按状态过滤。
  - stage 仅接受 ai_interview、written_test、first_interview、second_interview、third_interview、hr_interview，并筛选对应时间字段已填写的记录。
  - application_time_after 使用大于等于，application_time_before 使用小于等于，并通过 DRF DateTimeField 校验 ISO 8601 时间。
  - ordering 仅接受 created_at、updated_at、application_time 和六个阶段时间字段，可使用 - 前缀；默认保持 -updated_at、-id。
  - 所有可排序时间字段均使用 PostgreSQL NULLS LAST，正序和倒序均将空时间置于非空时间之后；自定义排序追加 id DESC 保持稳定。
  - 非法状态、阶段、时间和 ordering 返回 HTTP 400，响应结构为 code=VALIDATION_ERROR，并在 details 中标明字段。
  - 筛选、排序与 APP-004 分页组合工作，继续保持用户隔离及 next/previous query 参数。
