## 启动命令

前端：

```powershell
nvm use 20.19.0
Set-Location G:\job\frontend
npm ci
npm run dev
```

前端入口：`http://127.0.0.1:5173/`

E2E 本地联调时，仅将后端公开 API 前缀 `/api/v1` 代理到运行中的后端；`/api/auth.ts`、`/api/applications.ts` 等 Vite 源码模块不会被代理：

```powershell
nvm use 20.19.0
Set-Location G:\job\frontend
$env:VITE_API_PROXY_TARGET = "http://127.0.0.1:8000"
$env:VITE_DEV_PORT = "5174"
npm ci
npm run dev
```

`VITE_API_BASE_URL` 可用于需要直接访问 API origin 的构建环境；未设置时浏览器使用同源 `/api`，生产构建不会硬编码后端地址。

后端（先提供本地 PostgreSQL 的 `DATABASE_URL` 及必要 Django 环境变量）：

```powershell
Set-Location G:\job\backend
uv sync --frozen
uv run python manage.py migrate
uv run python manage.py runserver 127.0.0.1:8000
```
