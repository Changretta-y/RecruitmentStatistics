# Agent 交付模板

触发：创建任务单、RED/失败/通过报告、实现说明、角色交接或验收记录。仅使用与当前产物匹配的模板。

- 状态：PLANNED

## 业务规则与公开契约

## 输入、输出与错误行为

## 验收标准

- [ ] 可观察行为 1
