## 系统设计 PATCH 契约对照

- `PATCH /api/v1/applications/{id}/` 只修改提交的字段，成功返回 `200` 和更新后的完整记录。
- 时间字段接受带时区 ISO 8601 或 JSON `null`；`null` 表示清空，空字符串应被拒绝；当前阶段随时间字段变化重新派生。
- `id`、`user`、`current_stage`、`created_at`、`updated_at` 为只读；归属由当前用户 QuerySet 保护，跨用户记录返回 404。
