## 系统设计创建 API 契约对照

- `POST /api/v1/applications/` 要求 Bearer Access Token，合法请求返回 `201 Created` 和完整记录。
- 创建记录的归属由当前 Token 用户决定；`id`、`user`、`current_stage`、`created_at`、`updated_at` 为只读字段。
- 状态、备注、投递时间和六个阶段时间遵循模型默认值与 `null` 契约；时间接受 ISO 8601。
- 未认证请求返回 `401`；公司名/岗位名、状态和时间校验错误返回结构化 `400 VALIDATION_ERROR`；响应不得泄露密码或 Token。
