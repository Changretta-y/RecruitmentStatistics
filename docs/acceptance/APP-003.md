## 系统设计列表/详情契约对照

- 列表和详情均要求 Bearer Access Token；列表只返回当前用户数据，默认按 `updated_at DESC, id DESC` 排序并提供分页容器。
- 列表响应包含 `count`、`page`、`page_size`、`total_pages`、`next`、`previous`、`results`；详情返回完整投递记录和派生 `current_stage`。
- 他人记录或不存在记录统一返回 `404 NOT_FOUND`，不得泄露记录存在性；`user` 查询参数不能绕过服务端用户过滤。
- 未认证列表和详情均返回 `401`；分页精确参数、搜索筛选排序、修改和删除由后续任务负责。
